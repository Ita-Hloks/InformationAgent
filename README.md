# Information Agent

Information Agent 从 RSS/Atom 来源收集信息，筛选可追溯证据，并生成分析、搜索计划或联网搜索结果。

## 工作方式

```text
研究主题 + RSS/Atom 地址
  -> 采集来源内容
  -> 规范化文章与链接
  -> 按主题筛选并编号证据
  -> 基于证据执行后续分析或验证
  -> 输出可追溯的研究结果
```

确定性的数据处理由普通代码完成；LLM 只负责分析和生成需要语义判断的内容。没有证据时，工作流不得生成事实结论。

## 工程原则

- 阶段模块只能依赖其公开上游接口，编排层只组合工作流
- 公共字段、枚举与 JSON 输出属于对外契约，修改时必须同步更新模型、序列化器、消费者和测试
- 外部服务数据必须先转换为项目模型，不能直接透传到报告
- 每项变更至少覆盖正常路径和失败路径
